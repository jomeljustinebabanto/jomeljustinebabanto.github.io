# Jomel Justine Babanto | Personal Portfolio

Personal website for the GitHub Pages hands-on project.

## Files
- `index.html`: page structure and content
- `style.css`: layout, colors, and responsive styles
- `images/profile-placeholder.svg`: temporary image placeholder

## Replace the placeholder with your photo
1. Add your own photo to the `images` folder.
2. Name it `profile.jpg`.
3. In `index.html`, change the image source from `images/profile-placeholder.svg` to `images/profile.jpg`.

## Publish
In your repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
